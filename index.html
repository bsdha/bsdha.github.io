💉 Tính số bút Insulin

Nhập liều Insulin (UI) mỗi mũi tiêm trong ngày để tính tổng liều và số bút cần cấp mỗi tháng.
Liều: 0 UI/ngày
Cần cấp cho BN: 0 bút/tháng

🩸 Đổi đơn vị đường huyết

Chuyển đổi mg/dL ⇄ mmol/L và cảnh báo phân loại lâm sàng theo ngưỡng chẩn đoán.
mmol/L
— mg/dL
ℹ️Nhập chỉ số đường huyết để xem phân loại

Ngưỡng chẩn đoán tham khảo

ĐTĐ Đường huyết bất kỳ >200 mg/dL (11,1 mmol/L) · Đói (>8h) >126 mg/dL (7,0 mmol/L) · HbA1c >6,5%
Tiền ĐTĐ Rối loạn ĐH đói: 100–125 mg/dL (5,6–6,9 mmol/L) · HbA1c 5,7–6,4%
Hạ ĐH Đường huyết <70 mg/dL (<3,9 mmol/L)

Tính LDL-Cholesterol (công thức Friedewald)

Nhập Cholesterol toàn phần (TC), HDL-C và Triglycerid (TG) để ước tính LDL-C.
Công thức đang dùng (mmol/L): LDL-C = TC − HDL-C − TG/2.2
Công thức mg/dL: LDL-C = TC − HDL-C − TG/5

Tính eGFR (công thức CKD-EPI 2021)

Ước tính mức lọc cầu thận theo Creatinin huyết thanh, không dùng yếu tố chủng tộc (race-free), theo khuyến cáo mới nhất.

Vui lòng nhập đầy đủ và hợp lệ: tuổi (18-120) và creatinin (> 0).
--mL/phút/1.73m²
--

Áp dụng CKD-EPI Creatinine 2021 (race-free):
eGFR = 142 × min(Scr/κ, 1)α × max(Scr/κ, 1)-1.200 × 0.9938Tuổi × (1.012 nếu Nữ)
κ = 0.7 (Nữ) / 0.9 (Nam); α = -0.241 (Nữ) / -0.302 (Nam); Scr tính bằng mg/dL.

⚖️ Tính chỉ số khối cơ thể (BMI)

Nhập cân nặng và chiều cao để tính BMI và phân loại theo thang khuyến cáo cho người trưởng thành châu Á.

Vui lòng nhập đầy đủ và hợp lệ: cân nặng và chiều cao phải lớn hơn 0.
--kg/m²
--
BMI = Cân nặng (kg) ÷ [Chiều cao (m)]².
Phân loại (WHO, khuyến cáo riêng cho người châu Á): <18.5 Thiếu cân · 18.5–22.9 Bình thường · 23–24.9 Thừa cân · 25–29.9 Béo phì độ I · ≥30 Béo phì độ II.

Tra cứu tương tác thuốc

Công cụ tra cứu nhanh, kết hợp 3 nguồn: (1) CSDL rút gọn tự biên soạn tiếng Việt (có công dụng, liều tối đa, giải thích cơ chế), (2) CSDL DDInter 2.0 — ddinter2.scbdd.com (gần 2.000 thuốc, 160.000+ cặp tương tác, chỉ có mức độ, chưa dịch cơ chế), và (3) tra cứu mở rộng tự động từ nhãn thuốc FDA — Hoa Kỳ (tiếng Anh, dịch tự động). Cả 3 nguồn đều KHÔNG đầy đủ. Liều tối đa nêu ra là liều tham khảo cho người lớn, chức năng gan/thận bình thường, luôn cần hiệu chỉnh theo từng bệnh nhân. Vui lòng đối chiếu Dược thư Quốc gia Việt Nam hoặc ý kiến dược sĩ lâm sàng trước khi quyết định điều trị.
Nhập tên 2 thuốc (biệt dược hoặc hoạt chất), dùng phím ↑↓ để chọn gợi ý, nhấn Enter hoặc bấm nút để kiểm tra.

📥 Nạp danh sách thuốc "Trong Bệnh viện" từ file Excel

File cần có ít nhất 2 cột: Tên thương mại (hoặc "Tên biệt dược" / "Tên thuốc - hàm lượng") và Tên gốc (hoặc "Hoạt chất" / "Tên gốc, Hoạt chất"). Có thể có thêm cột "Dạng thuốc". Thuốc mới sẽ được cộng dồn vào danh sách hiện có (không xoá thuốc cũ), tự bỏ qua thuốc trùng tên.

📥 Nạp danh sách thuốc "Ngoài Bệnh viện" từ file Excel

Dùng cho chế độ Kê đơn ngoài Bệnh viện. Đã có sẵn danh mục khởi điểm (tên gốc/hoạt chất phổ biến theo nhiều nhóm bệnh) — có thể nạp thêm file Excel của riêng phòng khám (cùng định dạng cột như trên, không giới hạn số lượng thuốc) để bổ sung, thuốc mới sẽ cộng dồn, tự bỏ qua thuốc trùng tên.

Tìm thuốc theo tên thương mại hoặc tên gốc/hoạt chất — nhập liều dùng — nhấn Enter ở ô cuối để thêm vào toa.
⚠ Thuốc này đã có trong toa, không thể thêm trùng.

Cảnh báo tương tác / tương kỵ thuốc

    Nhập mật khẩu để vào Cấu hình

    Chuyển đổi định dạng tài liệu

    Chuyển đổi 2 chiều giữa PDF và Word / Excel / PowerPoint / Ảnh — tự nhận diện chữ (OCR) với bản scan, giữ nguyên bảng, căn lề, tiêu đề, in đậm. Tối đa 500 lượt chuyển miễn phí / tháng.

    Bấm để chọn file hoặc kéo-thả file vào đây (chọn được nhiều file cùng lúc)

    Công cụ PDF

    Ghép, tách, xoay, xóa trang, nén dung lượng và OCR file PDF — xử lý trực tiếp qua AI, không cần cài phần mềm.
    Chọn từ 2 file PDF trở lên — sẽ ghép theo đúng thứ tự trong danh sách (kéo để đổi thứ tự).
    🔗
    Bấm để chọn file hoặc kéo-thả nhiều file PDF vào đây
    Chọn 1 file PDF, nhập khoảng trang muốn tách (VD: 1-3, 5, 8-10). Để trống để tách mỗi trang thành 1 file riêng.
    ✂️
    Bấm để chọn file hoặc kéo-thả 1 file PDF vào đây
    Chọn 1 file PDF, chọn góc xoay và trang muốn áp dụng.

    Bấm để chọn file hoặc kéo-thả 1 file PDF vào đây
    Chọn 1 file PDF, nhập các trang muốn xóa khỏi tài liệu.
    🗑️
    Bấm để chọn file hoặc kéo-thả 1 file PDF vào đây
