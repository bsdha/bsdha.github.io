📋 Danh mục thuốc (tên thương mại + hoạt chất)

Nạp danh sách thuốc "Trong Bệnh viện" từ file Excel

1 bảng DUY NHẤT — vừa là danh mục để kê đơn, vừa là kho để dược sĩ thống kê. File cần có ít nhất cột Tên thương mại (hoặc "Tên biệt dược" / "Tên thuốc - hàm lượng"). Nếu file có thêm cột Tên gốc/"Hoạt chất", "Dạng thuốc", "ĐVT", "Đơn giá", "Tồn cuối" (báo cáo Xuất nhập tồn) thì sẽ tự nạp luôn giá + tồn kho. Có thể nạp nhiều lần từ nhiều file khác nhau (ví dụ: 1 file chỉ có tên/hoạt chất để kê đơn, sau đó nạp thêm file "Xuất nhập tồn" để cập nhật giá/tồn) — thuốc trùng tên sẽ tự cập nhật các cột có trong file mới, cột nào file không có thì giữ nguyên dữ liệu cũ; thuốc chưa có thì thêm mới.

Nạp danh sách thuốc "Ngoài Bệnh viện" từ file Excel

Dùng cho chế độ Kê đơn ngoài Bệnh viện. Đã có sẵn danh mục khởi điểm (tên gốc/hoạt chất phổ biến theo nhiều nhóm bệnh) — có thể nạp thêm file Excel riêng của phòng khám (cùng định dạng cột như trên) để bổ sung, thuốc mới sẽ cộng dồn, tự bỏ qua thuốc trùng tên.
